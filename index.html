How to read the visualizer

Move through the stream with the timeline or playback controls. The left panel shows the active Hoeffding Tree, while the memory panel shows subtrees that were pruned and retained for possible later reuse.

Event frames follow the pruning workflow used by MemoryHoeffdingTree. Yellow marks the active subtree that is about to be replaced. During successful reactivation, the selected stored subtree moves from memory to exactly that position in the active tree. If the replaced subtree is admitted to historical memory, it simultaneously moves in the opposite direction; otherwise it is not shown as stored. Purple indicates a subtree that is retained in historical memory; yellow is a temporary event highlight for the subtree or node currently involved in pruning or matching; cyan indicates that a stored subtree has been successfully reactivated into the active tree. Hover over tree nodes for node-level details and use the memory filter when many stored subtrees are present.

Thesis notation: the subtree being replaced corresponds to Ct, while the stored subtree selected for reactivation corresponds to M*.
